# Thetasoft

Thetasoft was created to simplify repetitive data analysis in Python, especially in experimental research.

## Wulkplot

Our flagship project is **Wulkplot**, a program designed to streamline data analysis workflows. It adds an abstraction layer to data handling and visualization while still allowing users to write custom scripts and interact with them and the data through a GUI.
